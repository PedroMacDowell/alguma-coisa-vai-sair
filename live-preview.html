Sistema Escolar

Preview de cadastro de alunos e boletim

Este arquivo era do projeto antigo. Ele agora apresenta o novo sistema escolar com login de professores, cadastro de alunos, lançamento de notas, cálculo de média e geração de boletim.

Abrir aplicação do cliente

Para executar o sistema completo, rode npm run dev:client e npm run dev:server.

Funcionalidades

  • Login de professor
  • Cadastro de alunos
  • Lançamento e soma das notas
  • Visualização de boletim
  • Dashboard com métricas de turma
